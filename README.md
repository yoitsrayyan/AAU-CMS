# AAU Course Manager (AAU-CMS)

AAU-CMS is an academic team project: a console-based C++ course management system for registering and dropping online or offline university courses, viewing a student's schedule, and displaying team credits.

## Build and run

Requirements:

- A C++ compiler with C++17 support
- `make` (optional)

Using the Makefile:

```bash
make
./bin/aau-cms
```

Clean the build output with:

```bash
make clean
```

The program is interactive and presents a menu for student sign-in, course registration, course dropping, schedule viewing, and team credits.
